# Where the research looks for projects (Arak)

Written 2026-10-17. This is the starting list now loaded on **Research → Where to look**. The list on that page is the real one: add, pause, delete or change how closely a source is read there. This file only records why each one was chosen.

## How the agent uses the list

- **Since 2026-10-19 every active source is checked every run, in code, before the two project lenses (Projects and Sales targets) start.** The results are handed to both lenses as leads to open and confirm; they then search openly for what the list does not reach.
- The setting on each source is how closely it is read, not how often:
  - **read closely**: its front page is read (for a site) and it is searched twice, 8 results kept
  - **read**: one search, 5 results
  - **skim**: one search, 3 results
- Each source on the page shows when it was last checked, how many results came back, and when it last led to a project. A source that never leads anywhere can be paused on that evidence.
- **Each source is read where it publishes** (since 2026-10-19, second pass). Search engines hold only scraps of social accounts: the first sweep found 0 posts on the Saudi Projects LinkedIn page and 1 on @addadruh, though both had posted that day.
  - **Instagram accounts**: their recent posts, full captions and dates, through the same Meta access the competitor numbers use. That access must be renewed by **2026-12-09**; if it lapses, these fall back to search.
  - **LinkedIn company pages**: the public page, read logged out, gives the latest ~10 posts. A source must be the page link (`linkedin.com/company/…`), not a name. Personal profiles are blocked to logged-out readers, so a person stays on search. LinkedIn's terms do not allow automated reading; it is a handful of public pages once a week, and a blocked page falls back to search.
  - **Sites with a feed** (saudigulfprojects, Construction Week, EnterpriseAM, Commercial Interior Design, ME Construction News): every new article, dated.
  - **Everything else** (MEED, Argaam, Zawya, Etimad, …): a search engine, plus the front page for "read closely". Paywalled sites give headlines and first lines.
- Only what is **new since the source's last check** goes to the lenses, items about our market first (the geography and the ICP regions decide what counts).
- If the check cannot run at all (no search provider), the lenses fall back to the old way: the list as names, tier 1 first.
- The agent also builds its own hashtags and keywords each run from our segments, region and project stages, in Arabic and English, and searches Instagram and LinkedIn with them. None of those are written into the system.
- After every run, Instagram or LinkedIn accounts and sites that led to a real project finding are **suggested** for the list. They wait for someone to accept them on the page.

## How a project is sized

- Our share of a project is set to **3–5%** of its total value (Sales → Targets → profile, "Our share of a project"). It's a rule of thumb: hotels, villas and fit-outs run higher, warehouses and infrastructure lower. A segment can have its own share.
- With our package sizes (best under SAR 500k, fine up to SAR 2M), the projects that fit are worth about **SAR 10M–67M in total**.
- A project much bigger than that is not pitched as one job. The agent has to name the piece that fits us (one hotel, the interiors, a fit-out floor, the controls package) and who holds it.
- **70%** of the sales-target searches go to projects we can do now, and 30% to bigger projects and new kinds of buyer.

## Worth knowing, not on the list

- **SCAVO / Ventures Onsite** (scavo.sca.sa, venturesonsite.com): a paid Saudi project database run with the Saudi Contractors Authority. It lists 20,000+ projects with contractor and consultant names. This is the strongest paid option if the free sources aren't enough. Pricing is on request.
- **Etimad through Firecrawl:** Firecrawl has a structured Etimad search, including "future projects" that agencies plan to tender. It's a good next step for government work (paid per call).
- **Limits:** the agent reads Instagram and LinkedIn through web search (`site:instagram.com`, `site:linkedin.com/posts`), so it only sees posts that search engines have indexed. Usually that's the recent public posts, not a full feed. LinkedIn has no API we can use. A paid Instagram index (Firecrawl lists one) could cover more if this proves too thin.
